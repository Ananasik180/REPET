# DevOps Practice Scripts

Учебные скрипты для автоматизации рутинных задач (в рамках подготовки к стажировке в DevOps).

## 📁 Содержимое

### 1. `analyze.py` (Python)
Скрипт для анализа CSV-файла с результатами учеников:
- Считает средний балл, медиану, минимум и максимум.
- Выводит список учеников с баллом ниже среднего.
- Пишет лог в файл `analyze.log`.
- Отправляет отчёт в Telegram (опционально).

**Как запустить:**
```bash
python3 analyze.py results.csv
